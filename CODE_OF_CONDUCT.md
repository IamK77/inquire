# Code of Conduct

This project adopts version 2.1 of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

The full text is available at the link above. In short:

- Be welcoming and respectful.
- Assume good faith; explain your reasoning.
- No personal attacks, slurs, doxing, or sustained disruption.

## Enforcement

If you experience or witness behavior that violates the Covenant, contact
the maintainers via the channel listed in [SECURITY.md](SECURITY.md).
Reports are handled confidentially and acted on per the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

## Scope

This Code of Conduct applies in all project spaces — the repository,
issue tracker, pull requests, releases, and any communication channel
the project may run — and when an individual is officially representing
the project in public.
